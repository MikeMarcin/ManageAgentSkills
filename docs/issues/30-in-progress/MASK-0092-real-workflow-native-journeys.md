## Objective and owned paths

Real-package disposable integration fixtures, native macOS/Windows role-output checks, compact qualification record and current readiness documentation.

## Bounded work

Run the SRV-shaped updated-skill/old-role scenario through only public MASK commands. Include a second consumer with distinct context and an explicit route override; a fresh clone with checked-in definitions; static no-script installation; consented dynamic setup and refusal; update/branch/recovery paths. Record exact upstream/candidate versions. Fresh-host discovery/loading claims need actual named-host observations; otherwise retain not_verified.

## Acceptance

Real package requirements are checked, no fixture helper pre-renders the roles, and no cross-consumer context/route leak occurs. Setup decline/failure cannot be called ready. Native output behavior is verified on macOS and Windows; provider model/effort execution is never inferred from files or configured banners. Repeated unchanged ensure does no setup work.
